# 楊芷翎 Yang Zhi Ling — Portfolio Website

UI/UX 設計師楊芷翎的個人作品集網站，使用純 HTML / CSS / JavaScript 打造，無框架、無建置流程，可直接以任何靜態網站服務部署（GitHub Pages、Netlify、Vercel 等）。

## 內容

- 個人簡介、技能與獲獎紀錄
- 精選作品
  - **OPENPOINT Redesign** — 完整 UX 案例研究（研究方法、設計策略、設計亮點、可用性測試與反思）
  - **(AI)dentity** — 第十六屆 Open HCI 人機互動工作坊主視覺設計
  - **生生死死，生生慢** — 國立台東大學美產系班展主視覺海報
- 工作經歷、學歷與課外活動時間軸
- 聯絡方式

## 技術

- 純手刻 HTML5 / CSS3（Grid、Flexbox、CSS 變數）
- Vanilla JavaScript（滾動顯示動畫、行動版選單）
- Google Fonts：Inter + Noto Sans TC
- 響應式設計，支援桌面／平板／手機

## 在本機預覽

```bash
cd portfolio-site
python3 -m http.server 8000
# 開啟瀏覽器造訪 http://localhost:8000
```

## 部署到 GitHub Pages

1. 將此專案 push 到 GitHub repository
2. 進入 repository 的 **Settings → Pages**
3. Source 選擇 `main` branch（`/root`），儲存
4. 稍待片刻即可透過 `https://<username>.github.io/<repo>/` 造訪網站
